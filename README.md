## Tuần 1 — HTML Cơ Bản (3 tiết)

### Bài 1. Các thẻ HTML cơ bản
- Làm quen cấu trúc tài liệu HTML: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`.
- Thực hành các thẻ nội dung: `<h1>...<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`, `<div>`, `<span>`.
- (Tham khảo thư mục: [`Bai1/`](Bai1/))

### Bài 2. Sử dụng các thẻ HTML cơ bản (tiếp theo)
- Kết hợp thẻ để tạo bố cục đơn giản; chèn ảnh, liên kết, danh sách.
- Thực hành thuộc tính thường dùng: `id`, `class`, `href`, `src`, `alt`, `title`.
- (Tham khảo thư mục: [`Bai2/`](Bai2/))

### Bài 3. Áp dụng thẻ để tạo website theo sơ đồ sitemap
- Dựa vào **sitemap** (hình minh họa) để tạo bộ trang HTML liên kết nhau.
- Sử dụng dữ liệu mẫu trong thư mục **`Bai3/`**; đảm bảo liên kết điều hướng hoạt động.
- (Tham khảo thư mục: [`Bai3/`](Bai3/))

### Bài 4. Liên kết nâng cao
- Liên kết tuyệt đối/tương đối, liên kết neo (`#anchor`), liên kết mail (`mailto:`) và tel (`tel:`).
- Mở liên kết ở tab mới với `target="_blank"` và chú ý `rel="noopener noreferrer"`.
- (Tham khảo thư mục: [`Bai4/`](Bai4/))

### Bài 5. Bảng (Table)
- Sử dụng thẻ **`<table>`** và các phần tử/thuộc tính liên quan để định dạng bảng:
  - Thẻ: `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`
  - Thuộc tính: `colspan`, `rowspan`, `scope`, …
- (Tham khảo thư mục: [`Bai5/`](Bai5/))

### Bài 6. Form (Biểu mẫu)
- Tạo form theo hình mẫu: **`<form>`**, **`<label>`**, **`<input>`**, **`<select>`**, **`<textarea>`**, **`<button>`**.
- Thực hành các loại input: `text`, `email`, `password`, `radio`, `checkbox`, `date`, `file`,…
- Liên kết `label` với input qua `for`/`id`, sử dụng `name` để gom dữ liệu.
- (Tham khảo thư mục: [`Bai6/`](Bai6/))
